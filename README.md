# Cervantes Realty — website facelift

Exact rebuild of [cervantesre.com](https://cervantesre.com).

## Stack

Vite + React 18 + TypeScript, Tailwind 3, react-router-dom v6, TanStack Query, Supabase listings CMS.

## Setup

```bash
npm install
npm run dev
```

Supabase credentials live in `src/config/supabase.ts` (facelift project).

Admin: `/admin/login` — `aaron@cervantesre.com`
